# 实现接口索引

本目录记录当前代码已经提供的客户端、战斗服务端与共享实现接口。设计目标仍以 `Docs/Design/` 为准；本文档不把规划中的能力描述为已实现能力。

| 模块 | 文档 | 当前状态 |
| --- | --- | --- |
| 基础战斗 HUD（F09-01） | [BattleHUD.md](BattleHUD.md) | 已实现原生布局、Lua 显示流程、本地预览，并在正式 Battle 路径接入 F05 权威弹匣、备用弹药和换弹进度；权威生命仍待 F06。模板 `MaxHP=500` 与设计生命值 100 冲突，待 F06 负责人处理 |
| 比赛状态（F08-01） | [MatchState.md](MatchState.md) | M1 最小实现：比赛阶段枚举、RoundId、阶段截止时间、阶段 RepNotify 与阶段许可查询。比分、胜负、结算、重置、分队、匹配均为 M2／M3 预留，未实现 |
| 玩家公共状态（F08-01） | [PlayerState.md](PlayerState.md) | M1 复制字段：队伍、击杀、死亡。`SetTeam` 已提供；分队流程与击杀／死亡写入属 M2，未实现 |
| 武器与弹药（F05-01 / F05-03 / F05-04 / F05-05） | [WeaponSystem.md](WeaponSystem.md) | F05-01：数据资产、角色复制、出生装备与权威弹药组件。F05-03：`Server_Fire` 校验链与权威扣弹。F05-04：服务器射线与命中解析，伤害提交待 F06。F05-05：`Server_Reload` 校验链、计时、弹药转移与中断。F05-02 表现层未实现 |
| 角色移动与行为限制（F04-04） | [CharacterMovement.md](CharacterMovement.md) | 已实现冲刺复制状态、服务器权威速度、阶段移动门控与冲刺／开火互斥。移动预测与平滑（F04-02）、死亡限制（F06）、结算阶段（M2）未实现 |
| 生命与重生（F06） | [HealthAndRespawn.md](HealthAndRespawn.md) | 已确定 F06-01 客户端所需的只读生命状态契约，并实现 HUD 无权威快照时的 `-- / --` 显示；服务器生命组件、Controller 正式绑定、伤害、死亡、重生和保护尚未实现 |

## 说明

- 上表的"当前状态"只描述已提交代码的行为；接口文档各节的"未实现／待验证"项以模块文档为准。
- F06 文档中的客户端契约当前标记为待服务器接口对齐；不得把契约草案描述为已可用的权威生命能力。
