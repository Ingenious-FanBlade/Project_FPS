# M1 与 M2 具体工作清单

来源：[overview 第 6.3 节](../Design/00-overview.md)，按客户端、服务端分类。

覆盖 F04、F05、F06、F08、F09 的全部 24 项原任务，并摘取 F12-03、F12-04 中与本期有关的联调检查，共关联 26 项原任务。
